# Run Logstash service

D:\open-framework\logstash-7.17.16\bin

   go to bin  folder , open  logstash.conf
   
    add the following configuration
	
	input {
		file {
			path => "D:/U360_SpringBootMicroservices/AppLogs/sb-microservices-gateway.log"
			start_position => "beginning"
		}
	}

	output{
		stdout {
			codec => rubydebug
		}
	
	elasticsearch {
		hosts => ["localhost:9200"]
		index => "sp-ms-ord-gateway-%{+yyyy.MM.dd}"
	}
}

D:\open-framework\logstash-7.17.16\bin>logstash.bat -f logstash.conf
